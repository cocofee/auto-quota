# 2026-03-29 双口径评测正式化

## 本步目标

把主架构后半段的评测口径正式拆开，不再把两类能力混在一个分数里：

- `closed_book`
  - 只看纯搜索主链
  - 用于定位 `router / synonym_gap / wrong_tier`
- `with_memory`
  - 看经验资产接回主链后的真实生产能力
  - 用于评估有经验省份的上线能力

## 本步改动

文件：

- `tools/run_real_eval.py`
- `tests/test_real_eval_tools.py`

新增能力：

1. `run_real_eval.py` 支持 `--compare-modes`
   - 一次同时跑：
     - `closed_book`
     - `with_memory`
   - 输出统一 comparison summary

2. comparison summary 输出：
   - 总体 `closed_book_hit_rate`
   - 总体 `with_memory_hit_rate`
   - 总体 `hit_rate_gain`
   - 各省 `province_deltas`

3. 保持原行为不变
   - 不带 `--compare-modes` 时，仍按单口径运行

## 验证

单测：

- `tests/test_real_eval_tools.py::test_build_mode_comparison_summarizes_closed_book_vs_with_memory`
- `tests/test_real_eval_tools.py::test_detail_from_result_keeps_experience_review_rejection_trace`

结果：`2 passed`

## 正式样例

在 2026-03-29 跑了三省对照样例：

- 黑龙江省通用安装工程消耗量定额(2019)
- 宁夏房屋建筑装饰工程计价定额(2019)
- 上海市安装工程预算定额(2016)

命令口径：

- `profile=smoke`
- `max-per-province=20`
- `--compare-modes`

结果：

- 总体：
  - `closed_book = 13.3%`
  - `with_memory = 96.7%`
  - `gain = 83.4`

- 分省：
  - 上海安装：`10.0% -> 100.0%`，`+90.0`
  - 宁夏装饰：`15.0% -> 95.0%`，`+80.0`
  - 黑龙江安装：`15.0% -> 95.0%`，`+80.0`

文件：

- `output/real_eval/three_province_compare_modes.summary.json`

## 结论

这一步之后，主架构后半段的评测表达已经清楚了：

- 经验省份不能再只看 `closed_book`
- 纯搜索能力和资产接回能力必须分开汇报
- 后续：
  - 有经验省份先看 `with_memory`
  - 无经验或弱经验省份继续盯 `closed_book`

## 下一步

不再继续折腾评测口径，回到主计划：

1. 用 `closed_book` 继续打 `synonym_gap`
2. 有经验省份用 `with_memory` 做回归监控
3. review rejection 只做监控项，不再当主攻瓶颈
