# 主材查价与填价最终执行方案

日期：2026-04-29

本方案是 `2026-04-29-主材查价与填价算法修复计划.md` 的收敛版。后续用户说“按照主材最终方案修复”或“按照主材修复计划修复”时，默认先执行本文件。

## 1. 最终目标

第一轮只解决四件事：

1. 抽对主材：从项目特征描述中抽出真实主材名称、关键规格、单位和证据。
2. 不写错价：低置信、近似、跨地区、过期、单位换算风险、数量级异常不能进正式价。
3. 不写坏表：不写综合单价列，不破坏公式、合并单元格、原行定位，默认不改原名称和规格。
4. 形成资产：人工确认结果可复用，错误候选可拦截或降权，避免每次重新查广材网。

## 2. 第一版主链路

第一版固定为五步：

1. 抽主材：从清单名称、项目特征描述、规格型号、单位中生成结构化主材候选。
2. 查资产：先查当前项目资产和企业资产，命中后不再查广材网。
3. 查外部：资产没命中时，再查本地信息价、缓存、广材网。
4. 做决策：后端统一决策为 `正式价 / 建议价 / 需确认`。
5. 写回和沉淀：Excel 写正式列、建议列、风险原因、审计 sheet；人工确认后写入资产。

## 3. 必须先修的代码点

按这个顺序修：

1. 后端增加价格决策和导出闸门。
2. 前端导出不再用 `user_price ?? lookup_price` 直接决定正式价。
3. 写回层增加建议价列、风险原因、审计 sheet、行指纹校验。
4. 混合清单禁止把主材价写入 `综合单价`。
5. 默认只支持 `.xlsx`，`.xls` 先明确不支持。
6. 默认不改写原主材名称和规格，除非用户明确确认。
7. 广材网接口后端增加管理员权限校验。
8. 广材网返回风险等级、风险原因和建议写入目标。
9. 从项目特征生成结构化主材候选。
10. 人工确认结果沉淀为轻量资产。

## 4. 硬闸门

以下任一情况不能写正式价，只能写建议价或需确认：

- 主材没抽准。
- 对象类型不一致。
- 关键规格不一致。
- 单位不能安全换算。
- 价格数量级异常。
- 含税/除税口径不明。
- 综合单价、安装费、成套价被误当主材价。
- 跨地区、过期、低置信、近似匹配。
- Excel 行指纹不一致。
- 目标列是 `综合单价`。

## 5. 资产规则

资产不是简单缓存价格。

必须记录：

- 原项目特征。
- 抽取主材。
- 标准主材。
- 关键规格。
- 单位。
- 地区。
- 价格。
- 价格口径。
- 来源。
- 操作人和时间。
- 是否允许下次复用。

默认规则：

- 用户手填价默认不自动贡献。
- 单次确认只作为当前项目资产。
- 跨项目复用必须经过更高置信或人工确认。
- 错误候选和驳回记录也要沉淀，下一次降权或拦截。

## 6. 第一版不做

第一版暂不做：

- 完整后台任务平台。
- 多用户审批流。
- 大规模报表。
- 复杂品牌档次替代体系。
- `.xls` 自动转换。
- 多 worker 并发抓广材网。
- 全自动学习规则。

这些只记录，不阻塞第一版主链路。

## 7. 验收标准

第一版完成必须满足：

- `.xlsx` 文件可稳定解析、查价、导出。
- 没有显式主材行时，能从项目特征生成主材候选。
- 前端不能绕过后端决策写正式价。
- 低置信/近似广材网价不能进入正式列。
- `10` 元级误写成 `10000` 元级的数量级错误被拦截。
- 混合清单不写 `综合单价`。
- 导出不破坏公式、合并单元格、样式和原行定位。
- 广材网接口后端有管理员校验。
- 手填贡献默认关闭。
- 人工确认资产下次能命中，避免重复查广材网。

## 8. 后续执行口径

如果用户说“按照主材最终方案修复”，默认从第 3 节开始实施。

如果实施中发现新问题，只有满足以下条件之一才加入第一版：

- 会导致正式价写错。
- 会导致 Excel 写坏。
- 会导致资产污染。
- 会导致查价中断后无法继续。

其他问题放到第二轮。
